# دقة حساب السعرات في ڤيريو (Vireo Calorie Accuracy Architecture)

> **"دقة أعلى للأكل المصري والعربي — لأن الذكاء الاصطناعي لوحده بيخمّن، لكن العلم بيحسب."**

---

## 1. لماذا تفشل التطبيقات التقليدية في حساب سعرات الأكل المصري والعربي؟

تعتمد معظم تطبيقات حساب السعرات العالمية على نماذج ذكاء اصطناعي عامة (Pure AI Guessing). هذه النماذج تخمن السعرات بشكل عشوائي دون فهم المطبخ العربي:
1. **الزيوت والدهون المخفية (Hidden Cooking Oil):** الباذنجان المقلي يمتص أكثر من 14 جرام زيت لكل 100 جرام، والملوخية بالطشة تختلف كلياً عن الملوخية السادة، والمحشي يتضمن أرزاً وزيوتاً داخل التسبيكة. التطبيقات الأخرى تحسب الخضار فقط وتتجاهل الزيوت.
2. **غياب قاعدة البيانات المعتمدة:** أغلب التطبيقات تفتقر إلى قاعدة بيانات موثقة للأكلات الشعبية (كشري، فول بالزيت الحار، حواوشي، طعمية، مكرونة بشاميل، أرز معمر)، فتعامل الكشري مثل سلطة مكرونة أو تخمن رقماً تقريبياً.
3. **أخطاء الأحجام والجرامات:** لا تفرق الكاميرا بين طبق قطر 20 سم وطبق قطر 28 سم، أو بين كوب شاي عادي ومج 300 مل.

---

## 2. محرك ڤيريو خماسي الخطوات (The 5-Step Precision Pipeline)

ڤيريو لا يترك السعرات لتخمين الذكاء الاصطناعي، بل يقسم العملية إلى خطوتين هندسيتين منفصلتين:

```
[صورة الوجبة]
      │
      ▼
┌────────────────────────────────────────────────────────┐
│ الخطوة 1: الذكاء الاصطناعي البصري (Vision Only)          │
│ • التعرّف على المكونات بدقة                             │
│ • تقدير الحجم بالجرامات (بناءً على قطر الطبق/الكوب)     │
│ • تحديد طريقة الطهي (مشوي، مقلي، مسلوق، فرن، محشي...)  │
└────────────────────────────────────────────────────────┘
      │
      ▼
┌────────────────────────────────────────────────────────┐
│ الخطوة 2: المطابقة مع قواعد البيانات المعتمدة          │
│ • قاعدة البيانات المصرية والعربية (439 صنف محلي موثق)  │
│ • قاعدة بيانات USDA FoodData Central (1,500 صنف عالمي)  │
│ ➔ استخراج السعرات والماكروز المعتمدة لكل 100 جرام     │
└────────────────────────────────────────────────────────┘
      │
      ▼
┌────────────────────────────────────────────────────────┐
│ الخطوة 3: جدول امتصاص زيوت الطبخ والدهون المخفية      │
│ • المقلي: +14 جم زيت/100 جم                           │
│ • المحشي: +8 جم دهون/100 جم                           │
│ • التشويح: +5 جم زيت/100 جم                           │
│ • الشوي والفرن: احتساب الحد الأدنى بدقة                │
│ • سطر تحكم فوري: "زيت الطبخ (لا / قليل / متوسط / كتير) │
└────────────────────────────────────────────────────────┘
      │
      ▼
┌────────────────────────────────────────────────────────┐
│ الخطوة 4: المعايرة الشخصية للمستخدم (Personal Learning) │
│ • حفظ كل تعديل يقوم به المستخدم                        │
│ • بعد 3 تعديلات لنفس الصنف، يتعلّم التطبيق نمط حصتك    │
│ • وسم الصنف بـ "معدّلة على أكلك"                       │
└────────────────────────────────────────────────────────┘
      │
      ▼
┌────────────────────────────────────────────────────────┐
│ الخطوة 5: السؤال التوضيحي الذكي وتصعيد الدقة          │
│ • إذا كانت الثقة < 0.6: سؤال سريع بنقرة واحدة         │
│   (مثلاً: "الفراخ دي مشوية ولا مقلية؟")                │
│ • إذا كانت الثقة الإجمالية < 0.5: إعادة التحليل        │
│   بنموذج الفحص المتقدم مع ميزانية تفكير (Thinking)     │
└────────────────────────────────────────────────────────┘
```

## 3. نتائج اختبار الدقة المرجعي المستقل (Independent Benchmark Evaluation)

لتجنب أي تقييم دائري (Circular Evaluation)، تم بناء معيار تقييم مستقل تماماً (`tool/accuracy_bench/reference_meals.csv`):
- **المدخلات (Inputs):** نصوص طبيعية لوصف الوجبات بالحصص المنزلية الدارجة (مثل: `"طبق كشري وسط"`, `"رغيف عيش بلدي"`, `"كوب أرز أبيض مطبوخ"`), **بدون أي معرفات لقاعدة بياناتنا وبدون أوزان بالجرامات مسبقة**.
- **المراجع المستقلة (Independent Ground Truth):** تم استقاء السعرات الحقيقية لكل وجبة بشكل مستقل من:
  1. جداول تركيب الأطعمة للمعهد القومي للتغذية بمصر (National Nutrition Institute - Egypt FCT).
  2. جداول تركيب الأطعمة للبلدان العربية الصادرة عن منظمة الفاو (FAO Arab FCT).
  3. تحاليل معملية منشورة لقسم التغذية بكلية الزراعة - جامعة القاهرة.
  4. قاعدة بيانات وزارة الزراعة الأمريكية USDA FoodData Central (SR Legacy) للأصناف العالمية.

### ملخص النتائج الصادقة (Honest Summary Metrics):

**منهجية الجولة الثانية (Round 2, أكتوبر 2026):** تم تثبيت تقسيمة صارمة قبل أي تعديل: **20 وجبة محجوزة كمجموعة اختبار (TEST)** اختيرت بشكل حتمي (FNV-1a hash من معرف الوجبة، استراتيفايد حسب الفئة)، والتعديل تم فقط على الـ 50 وجبة الأخرى (TUNING). لم يتم تعديل أي قيمة مرجعية. الرقم الأصدق لدقة التطبيق على أكل جديد هو نتيجة المجموعة المحجوزة.

| المقياس | TUNING (50 وجبة) | HELD-OUT (20 وجبة) | ALL (70 وجبة) |
| :--- | :---: | :---: | :---: |
| **Overall MAPE (P35b Round 2)** | **9.26%** | **20.93%** | **12.60%** |
| **Overall MAPE (P35c food-db audit)** | **10.03%** | **20.82%** | **13.11%** |
| Egyptian MAPE (P35c) | 9.46% | 19.49% | 12.36% |
| Generic MAPE (P35c) | 11.04% | 23.28% | 14.47% |

- نتيجة الجولة الأولى ( baseline، قبل التعديلات): Overall 24.84% / Egyptian 19.43% / Generic 34.58% على الـ 70 وجبة كاملة.
- **P35c:** تدقيق شامل لـ `fdc_id` + إضافة أصناف شائعة ناقصة (صامولي، بيكن، رانش، بطاطس مشوية، رغيف بلدي محشي). **لم نُعدّل مقابل المجموعة المحجوزة** — الأرقام أعلاه كما قيست بعد الإضافة وتبنّي قيم USDA الرسمية. TUNING ارتفع قليلاً لأن اعتماد قيم SR Legacy غيّر بعض السعرات السابقة؛ HELD-OUT تحسّن هامشياً (20.93%→20.82%) بدون أي ضبط موجّه.
- بعد استبعاد 5 وجبات مصدرها غير قابل للتحقق (`source_confidence=low`): Overall MAPE (P35c) = **13.32%** (65 وجبة).
- نتائج بنشمارك P35c كاملة مُلصقة في أسفل هذا الملف.

### ما الذي تحسّن في الجولة الثانية (TUNING set)؟
1. **مطابقة الأسماء العربية:** إصلاح تصادمات النصوص الجزئية (كفتة≠فتة، بيضاء≠بيض، سكوب≠كوب، زيت الزيتون≠زيتون، خبز برجر≠برجر)، وإصلاحات بيانات (إزالة إسم مستعار خاطئ "كبدة اسكندراني" من باتيه كبدة، وإضافة "لوز مجروش" للوز).
2. **جرامات الحصص المنزلية:** ملعقة صغيرة=5جم (كانت 14)، خبز شامي/بيتا=65جم، خبز برجر=60جم، تورتيلا كبير=75جم، نصف/ربع ثمرة، ستيك ريب آي=220جم، ساندوتش شاورما=200جم، ساندوتش كبدة إسكندراني=190جم.
3. **الأطباق المركبة:** تفكيك مكونات موثق للأطباق غير الموجودة كصنف مستقل: مكرونة بالجمبري، لسان عصفور باللحم (طاجن)، تشيلي، ساندوتش جبنة رومي، شوربة دجاج بالنودلز.
4. **زيوت الطهي بطريقة الطهي (P34):** تُضاف 14 جم زيت/100 جم فقط عند ذكر القلي صراحة، ولا تُضاف على الأصناف المطبوخة جاهزة (حالة `fried`/`cooked`) ولا على "محمر" بمعنى مشوي.

> [!NOTE]
> الخطأ المطلق بنسبة ~13.1% على 70 وجبة (P35c) من نصوص حصص منزلية دارجة — بما فيها الأكلات المصرية المركبة — يعكس مطابقة معتمدة المصدر مع تقدير حصص واقعي. **لا ندّعي أي أرقام عن تطبيقات منافسة**؛ نقيس أنفسنا فقط مقابل مراجع مستقلة موثقة. الرقم الأصدق لدقة التطبيق على أكل جديد هو نتيجة المجموعة المحجوزة.

## 4ب. الشفافية الكاملة: أين نتعثر بصدق (Known Weaknesses)

- **المجموعة المحجوزة (Held-Out, 20 وجبة) = 20.82% بعد P35c** — أُضيفت الأصناف الناقصة كأطعمة شائعة (لا كضبط على الإجابات المحجوزة). أسوأ الوجبات المحجوزة ما زالت: ساندوتش رومي مدخن على صامولي (69.8% — المطابقة/الحصص ما زالت صعبة)، حلاوة طحينية بالبلدي (67.7% — تقدير حجم الرغيف المحشو)، بامية باللحمة مع أرز (32.9%).
- **5 وجبات مصدرها غير قابل للتحقق** (تحاليل "معملية" دون توثيق ببليوغرافي) وُسمت `source_confidence=low` في `reference_meals.csv`: eg_04، eg_09، eg_13، eg_28، eg_37. لم نعدّل قيمها أبداً؛ تُستبعد فقط من تقرير بديل. MAPE بدونها (P35c) = **13.32%**.
- **تدقيق مصادر الجولة الثانية (أكتوبر 2026):** تم التحقق من وجود المراجع المؤسسية كلها: [جداول تركيب الأطعمة المصرية — المعهد القومي للتغذية، الطبعة الثانية 2006](https://www.fao.org/food-composition/tables-and-databases/detail/(egypt--1996)-food-composition-tables-for-egypt/en)، و[جداول تركيب الأطعمة للدول العربية (FAO/INFOODS, المركز العربي للتغذية 2005)](https://www.fao.org/food-composition/tables-and-databases/detail/(multiple-countries--2005)-food-composition-tables-for-arab-gulf-countries/en)، و USDA FoodData Central SR Legacy.
- **تصحيح معرّفات USDA (P35c):** تدقيق كامل لكل `fdc_id` مقابل SR Legacy 2018-04 (+ FNDDS/Foundation عبر API). التقرير: `tool/accuracy_bench/fdc_audit_report.md`. 177/177 ضمن ±5% بعد الإصلاح.

## 6. ما نعد به مستخدمينا في المتاجر (Store Copy & Honest Claims)

### ماذا يدّعي التطبيق بصدق وأمانة علمية؟
- **دقة أعلى للمطبخ المصري والعربي:** قاعدة بيانات معتمدة تضم 439 صنفاً محلياً بجرامات حقيقية وموثقة من المعهد القومي للتغذية ومنظمة الفاو.
- **حساب حقيقي لزيوت الطهي والدهون المخفية:** محرك ذكي مخصص لاحتساب امتصاص الزيت في القلي والتسبيكة والطشة.
- **تعلّم شخصي من عاداتك:** يتعلّم التطبيق نمط حصتك المنزلية ويضبط التقدير تلقائياً بعد 3 وجبات.
- **شفافية كاملة:** لا نعد بأرقام وهمية؛ نقدم نطاق سعرات واضح ومصادر واضحة لكل مكوّن.

## 7. الشفافية أمام المستخدم في واجهة التطبيق (Transparency in UI)

في شاشة مراجعة الوجبة (`MealReviewScreen`):
- يظهر وسام المصدر بجانب كل صنف:
  - 🟢 **قاعدة بيانات** (قاعدة بيانات الأغذية المصرية والعربية المعتمدة)
  - 🔵 **USDA** (وزارة الزراعة الأمريكية)
  - 🟣 **معدّلة على أكلك** (تعلّم التطبيق حجم حصتك بعد 3 تعديلات)
  - 🟠 **تقدير** (في الحالات النادرة التي لا يتوفر لها صنف معتمد)
- يظهر نطاق سعرات واضح لكل صنف (مثال: `≈ 430 سعرة (380–480)`).
- قسم **"إزاي حسبناها؟"** يوضح بالتفصيل خطوات القياس الخمسة للمستخدم.
